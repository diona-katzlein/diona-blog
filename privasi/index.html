Kebijakan Privasi

Terakhir diperbarui: 15 November 2026.

Halaman ini menjelaskan data apa yang dikumpulkan saat Anda mengunjungi Isekai Blog (baca.readme.id), dan bagaimana data itu digunakan.

1. Data yang Kami Kumpulkan

Blog ini adalah situs statis yang di-host di GitHub Pages. Kami tidak meminta Anda membuat akun, tidak meminta nama, email, atau password, dan tidak menyimpan data pribadi apa pun di server kami. Satu-satunya hal yang Anda kirimkan ke situs ini adalah permintaan halaman yang Anda buka — seperti halnya situs mana pun.

2. Log Server

GitHub Pages sebagai penyedia hosting dapat mencatat log teknis standar (alamat IP, jenis browser, halaman yang dikunjungi, dan waktu akses) untuk keperluan keamanan dan operasional, sesuai kebijakan privasi GitHub. Kami tidak mengakses maupun mengolah log tersebut untuk mengidentifikasi pembaca secara pribadi.

3. Cookie dan Iklan Pihak Ketiga

Blog ini menampilkan iklan melalui Monetag. Penyedia iklan pihak ketiga dapat menggunakan cookie dan teknologi serupa untuk menampilkan iklan, mengukur kinerjanya, dan mencegah penipuan iklan. Kami tidak mengendalikan cookie pihak ketiga tersebut; Anda dapat mengelola atau menghapus cookie melalui pengaturan browser Anda.

Blog ini juga memuat pustaka dari CDN pihak ketiga (misalnya Font Awesome dan highlight.js) untuk tampilan dan pewarnaan kode. Pustaka tersebut dapat mencatat permintaan unduhan file sesuai kebijakan masing-masing penyedia.

4. Tautan ke Situs Lain

Artikel di blog ini banyak menautkan ke sumber resmi (NVD, CISA, Have I Been Pwned, dan penerbit berita keamanan). Kebijakan privasi situs-situs tersebut berlaku masing-masing saat Anda mengklik tautan keluar.

5. Privasi Anak

Konten blog ini ditujukan untuk pembaca umum, terutama profesional dan pelajar di bidang teknologi informasi. Kami tidak secara sadar mengumpulkan data dari anak di bawah umur.

6. Perubahan Kebijakan

Kebijakan ini dapat diperbarui dari waktu ke waktu; tanggal pembaruan selalu tercantum di atas. Penggunaan blog setelah perubahan berarti Anda menyetujui kebijakan yang berlaku saat itu.

7. Hubungi Kami

Pertanyaan tentang kebijakan ini dapat disampaikan melalui halaman Kontak.
